
# SRL Labs

## What is in this organisation?

This GitHub organisation is the home for open source research projects related to
[SR Linux](https://www.nokia.com/ip-networks/service-router-linux-NOS/) . The projects in this organisation are not
intended for commercial use. Repositories in this organisaiton do not have an open source steward as it is defined in the
European Union Cyber [Resliliency Act Article 3(14)](https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=OJ:L_202402847#art_3).
